# python-expense-tracker
A Python expense tracker demonstrating input validation, expense aggregation, category-wise calculations, and exception handling.

## Overview
A beginner-friendly Python project that records expenses and calculates overall and category-wise spending.

## Features
- **Add Expenses:** Record an expense amount, category, and description.
- **Amount Validation:** Reject expense amounts that are zero or negative.
- **Total Expense Calculation:** Calculate the sum of all recorded expenses.
- **Category-wise Aggregation:** Calculate total spending for a selected category.
- **Expense Display:** Display all recorded expenses with their categories and descriptions.
- **Exception Handling:** Handle invalid expense amounts using `ValueError`.

## Technologies Used
- Python 3
- Lists and dictionaries
- Functions and loops
- Conditional statements
- Exception handling
- Basic data aggregation

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:
        expense_tracker.py


## Concepts Practiced
This project helped me practice modular programming, validation, iteration, aggregation logic, dictionary-based data storage, and exception handling.

## Limitations
- Expenses are stored in memory and disappear when the program exits.
- The current version uses predefined test scenarios rather than interactive user input.
- It does not yet include persistent storage or visual reports.

## Future Improvements
- Add interactive expense entry.
- Store expenses in CSV or SQLite.
- Add monthly spending summaries.
- Generate charts for category-wise spending.
- Export expense reports.
